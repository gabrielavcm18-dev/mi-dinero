# Mi Dinero · Gaby

Versión reconstruida y mejorada de la app financiera personal.

## Incluye
- Dashboard mensual
- Ingresos y gastos
- Movimientos con categorías
- Deudas y pagos
- Meta de ahorro
- Margen disponible
- Persistencia local en el dispositivo
- Exportación de respaldo JSON
- Diseño responsive para teléfono y computadora
- Estética femenina, elegante y rosa/blush

## Publicar gratis con GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html` y `manifest.json`.
3. En Settings → Pages, selecciona Deploy from branch → main → /(root).
4. GitHub te dará la dirección pública.

Los datos financieros se guardan en el navegador mediante localStorage. Esta versión no envía los datos a un servidor.
